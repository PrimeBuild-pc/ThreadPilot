# ThreadPilot v1.7.7 — Efficiency mode, reliable rules and a clearer UI

**Stable release. This build does not include the experimental Game Boost feature.** Game Boost and its additional topology changes are reserved for the separate v1.7.8-beta.1 pre-release, where hardware testers can opt in.

## Efficiency mode / EcoQoS

- Choose **Windows decides**, **On (EcoQoS)** or **Off (HighQoS)** for a running process or a persistent rule.
- CPU priority remains independent; combine EcoQoS with Low priority if you want Task Manager-like behavior.
- The selected-process summary shows the observed mode and warns when the system-wide Power Throttling tweak overrides it.
- EcoQoS was independently verified by @SA-Mousavichashmi on an Intel i5-12500H, Windows 11 build 26300.9711: live On/Off/system-managed behavior, saved rules, independent CPU priority and access-denied handling. See [issue #66](https://github.com/PrimeBuild-pc/ThreadPilot/issues/66).

## Rules and configuration reliability

- Configuration exports now include persistent process rules. Legacy backups still import without replacing rules they do not contain.
- Imports are validated before writes, show a replacement summary and roll back on failure.
- Overlapping rules use deterministic precedence: process name, wildcard path, exact path, then edit order. The process summary reports conflicts.
- Rule edits, including CPU selections, are staged and saved together. Process details provide explicit Apply actions and priority undo tied to the same PID and process start time.
- Pausing automation no longer blocks manual process management.

## UI refresh

- Labelled navigation, search/filter/column controls, clearer process details and localized rule options.
- Windows 11-style Settings and Tweaks rows, remembered layout/filter/window choices, and fixes for narrow windows and 150% scaling.
- Updated translations across all seven supported languages.

## Validation and downloads

Native EcoQoS integration tests now run on a Windows 11-era kernel (Windows Server 2025); Server 2022 build 20348 rejects power-throttling read-back. The real Set/Get round-trip test remains enabled.

Download the x64 installer for a normal installation or the portable ZIP. Upgrading preserves settings; export a configuration backup before switching between stable and preview builds. Install the desired channel manually when switching back from a newer beta.

Artifacts are **unsigned** while code-signing enrollment is pending, so Windows SmartScreen may warn. Verify the attached SHA256 checksums. Uninstalling removes ThreadPilot-owned user data.
