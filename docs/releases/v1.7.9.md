# ThreadPilot v1.7.9

This release fixes saved-rule monitoring that could stop responding after Windows sleep or hibernation ([#95](https://github.com/PrimeBuild-pc/ThreadPilot/issues/95)).

- Monitoring recreates its WMI subscriptions after resume and session unlock, rescans processes already running, and evaluates saved rules again.
- A lightweight watchdog recovers stopped or silent subscriptions. When WMI is unavailable, polling keeps detecting processes if fallback polling is enabled; WMI retries run independently of fallback polling.
- Automatic startup and manual Start use the same startup path, including the initial process scan and rule evaluation.
- Path-based rules retry when a process starts before Windows exposes its executable path.
- File diagnostics initialize before automation starts and record recovery attempts and results.

Settings and saved rules are preserved. Artifacts remain unsigned while code-signing enrollment is pending; SHA-256 checksums are included with the release.
