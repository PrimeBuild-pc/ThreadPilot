- Captured on 2026-11-12 from the official **ThreadPilot v1.7.9** portable build (SHA256-verified against the release `SHA256SUMS.txt`), real Windows 11 UI, English interface, 1600 × 960 window, 16 logical CPUs.
- Only navigation was used: no rule, tweak, power plan or Game Boost was applied while capturing. The Processes list is filtered on Notepad (sample process, selected but not changed) so no other process names appear.
- Power plan names are blurred in `power-plans-light.png`. Images are palette-optimized PNGs, otherwise unedited.
- `overview-themes.png` combines the matching dark and light Processes captures with a diagonal seam; both show the same list.
- Game Boost is off by default and not yet validated on dual-CCD Ryzen X3D and Intel hybrid CPUs. These screenshots are not performance benchmarks.
